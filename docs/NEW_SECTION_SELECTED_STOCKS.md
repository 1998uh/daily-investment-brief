# 新增板块：今日精选标的

## 功能说明

在日报末尾新增"💎 今日精选标的"板块，基于所有作者观点的交叉分析，提取共识度最高的投资标的和方向。

## 板块位置

位于日报的倒数第二部分：
```
...
## N、🔭 下期关注（待验证假设）

## N+1、💎 今日精选标的    ← 新增板块

---
免责声明
```

## 板块内容结构

### 1. 最值得关注的个股/ETF（表格）

| 标的代码 | 标的名称 | 推荐理由（来源作者） | 风险提示 |
|---|---|---|---|
| 600519.SH | 贵州茅台 | 三位作者共同看好消费复苏，财报超预期（作者A、作者B、作者C） | 估值处于历史高位，需关注业绩兑现 |
| 512400.SH | 有色ETF | 供给约束+宏观溢价回归（作者D、作者E） | 依赖美联储降息预期，地缘政治风险 |

**提取规则**：
- ✅ 只列被**至少2位不同作者**明确看好的标的
- ✅ 推荐理由必须具体到作者和核心逻辑
- ✅ 风险提示来自原文或明显的市场共识
- ✅ 如无符合条件的标的，表格留空并说明

### 2. 今日最强共识方向（列表）

列出被**至少3位作者**共同看好的板块/主题：
- **PCB板块**：5位作者提及（作者A、作者B、作者C、作者D、作者E）
- **AI算力**：4位作者提及（作者F、作者G、作者H、作者I）
- **有色金属**：3位作者提及（作者J、作者K、作者L）

如果没有明显共识：
> 今日作者观点较为分散，未形成明显方向共识

### 3. 编辑说明

固定的免责声明和使用建议：
```
本板块基于当日所有作者观点的交叉分析，提取共识度最高的标的和方向。
**这不是投资建议**，仅作为信息汇总参考。标的选择应：
- 结合个人风险承受能力
- 关注原文中的风险提示
- 验证支持逻辑是否仍然成立
```

## 核心特点

### ✅ 优势
1. **共识提取**：从多位作者观点中自动提取共识
2. **风险平衡**：既有推荐理由，也有风险提示
3. **可追溯**：每条推荐都标注来源作者
4. **阈值控制**：避免单一作者观点被误导为共识
5. **可为空**：没有共识时不强行凑数

### ⚠️ 注意事项
1. **不是投资建议**：仅为信息汇总，不构成买卖建议
2. **需人工复核**：LLM 提取的共识需要用户自行验证
3. **实时性限制**：基于采集时间窗口内的文章
4. **作者权重相同**：未区分作者的历史胜率

## 实现方式

### LLM 模式
通过 prompt 模板指导 LLM：
1. 扫描所有作者对个股/ETF/板块的看法
2. 统计被多位作者共同看好的标的
3. 提取每位作者的核心逻辑
4. 汇总原文中的风险提示
5. 按共识度排序输出

### Fallback 模式
简化版本，仅提供：
- 提示此为 fallback 模式
- 说明完整功能需 LLM 支持
- 保留板块结构以维持格式一致性

```markdown
今日作者观点较为分散，未形成明显方向共识
```

## 与其他板块的关系

| 板块 | 内容 | 区别 |
|---|---|---|
| 博主看好方向汇总 | 每位作者各自的看好方向 | 平铺所有观点，不做交叉分析 |
| 今日注意事项 | 操作建议+风险提示的总结 | 更关注操作层面，不聚焦具体标的 |
| **今日精选标的** | **多位作者共同看好的标的** | **提取共识，突出交叉验证** |
| 下期关注 | 可验证的投资假设 | 更严格，需要明确的验证条件和期限 |
